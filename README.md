# Spendie ♡ — Your Money, Your Little World

A student-friendly personal finance dashboard designed to make tracking money simpler, clearer, and a little more fun.

🌷 **Live Website:** https://palaksharma31741-eng.github.io/Spendie/

## ✨ About the Project

Spendie is a pastel-themed personal finance website created to help students keep track of their income, expenses, and monthly spending budget in one place.

The goal is to make everyday money management feel simple and approachable, especially for students who are learning to manage their finances independently.

## 🌸 Features

- **Dashboard:** View your total balance, income, and expenses.
- **Transaction Tracking:** Add and manage financial transactions.
- **Monthly Budget:** Set a monthly spending limit.
- **Budget Progress:** Track monthly spending against your budget.
- **Remaining Budget:** See how much of your monthly budget is left.
- **Daily Spending Guide:** Get a suggested daily spending amount based on your remaining budget and the days left in the month.
- **Pastel UI:** A soft, student-friendly interface designed for a pleasant user experience.
- **Browser Storage:** Save transactions and budget settings using browser local storage.

## 🛠️ Technologies Used

- **HTML5** — Website structure
- **CSS3** — Styling, layout, and responsive design
- **JavaScript** — Transaction management, budget calculations, and interactive functionality
- **Browser localStorage** — Saving transaction and budget data in the browser
- **GitHub** — Source code hosting and version control
- **GitHub Pages** — Website deployment and hosting

## 🚀 Run the Project Locally

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

Alternatively, open the project folder in Visual Studio Code and run `index.html` in your browser.

No backend server is required for the current version.

## 💾 Data Storage

Spendie currently uses browser local storage to save transactions and budget settings.

This means the data is stored in the browser on the device being used. It does not automatically synchronize between devices or users.

The current version does not include user authentication or cloud-based data storage.
